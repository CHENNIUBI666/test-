# Xiaobu IME Bypass
It is a LSPosed module for bypass Xiaobu IME auth verify on ColorOS 16 and lower (OSDK lower than 40) devices.

# How to use
1. Download from GitHub Releases.
2. Sign the APK by yourself using MT Manager or other tools you know.
3. Install Xiaobu IME & the Bypass Module.
4. Enable the Bypass Module in LSPosed and select Xiaobu IME.
5. Force-stop Xiaobu IME and restart it.
6. Enjoy!
